# nano-kontroller

6 Channel LED effect controller using Arduino Nano or Uno R3.

Uses interrupt-based [TinyIRReceiver](https://github.com/Arduino-IRremote/Arduino-IRremote#tiny-nec-receiver-and-sender) from grander [Arduino-IRremote](https://github.com/Arduino-IRremote/Arduino-IRremote) library to keep all PWM channels free for maximum LED capacity.
